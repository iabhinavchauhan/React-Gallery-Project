# React Gallery

A modern and responsive image gallery built with **React.js**. This project demonstrates component-based UI development, responsive layouts, and clean frontend design.

## Live Demo

🔗 **[React Gallery](https://iabhinavchauhan.github.io/React-Gallery-Project/)**

## ✨ Features

* 📸 Beautiful image gallery
* ⚛️ Built with React.js
* 📱 Fully responsive design
* 🎨 Clean and modern UI
* 🧩 Component-based architecture
* ⚡ Fast and lightweight
* 🖥️ Works across desktop, tablet, and mobile devices

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/iabhinavchauhan/React-Gallery-Project.git
```

Navigate to the project:

```bash
cd React-Gallery-Project
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.
