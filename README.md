# React Based Gallery Project 

🔗 **[React Gallery](https://iabhinavchauhan.github.io/React-Gallery-Project/)**

##  Features
* Beautiful image gallery
* Clean and modern UI
* Fast and lightweight
* Works across every device

##  Tech Stack

* **React.js**
* **JavaScript (ES6+)**
* **HTML5**
* **CSS3**
* **Vite**
* **Git & GitHub**

##  Installation & Setup
Clone the repository:

```bash
git clone https://github.com/iabhinavchauhan/React-Gallery-Project.git
```

Navigate to the project:

```bash
cd React-Gallery-Project
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
